Content-Slate Scenario Planner

Personal project on public data. Slate: 14 new animated films, first Top 10 runs starting 2025-01-12 to 2026-08-30. Data: Netflix Top 10 global weekly data (official, top10.netflix.com) + IMDb public datasets. See README for sources, definitions, and limitations. Charts are interactive where noted: hover points for values.

Forecast check (one-step-ahead, 22 titles, first runs ≥ 4 weeks)

Decay-curve model MAPE: 16.8%; naive (repeat last week) MAPE: 50.6%; median-shape model MAPE: 32.9%. Decay fell back to naive on 0 of 22 titles (too few post-peak points to fit). Pooled post-peak retention ratio: 0.849.
